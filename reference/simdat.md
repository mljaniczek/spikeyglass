# Simulated three-group network data

A simulated dataset with known graphs: K = 3 groups, p = 50 variables
and n = 150 observations per group, generated by
[`simulate_ssjgl_data`](https://mljaniczek.github.io/spikeyglass/reference/simulate_ssjgl_data.md)
with scale-free graphs (seed 2022). The groups share a scale-free base
graph; each group's graph is the base graph with 5\\ group 1.

## Usage

``` r
simdat
```

## Format

A list with elements

- Y:

  List of 3 data matrices, each 150 x 50, with columns `V1, ..., V50`.

- g:

  List of 3 true adjacency matrices (50 x 50, 0/1).

- Omega:

  List of 3 true precision matrices (50 x 50).

## Source

`data-raw/simdat.R` in the package sources.

## Examples

``` r
str(simdat, max.level = 1)
#> List of 3
#>  $ Y    :List of 3
#>  $ g    :List of 3
#>  $ Omega:List of 3
sapply(simdat$g, function(a) sum(a[upper.tri(a)]))  # edges per group
#> [1]  49 106 104
```
