# Simulated Network Data

A simulated dataset for 3 groups with slightly different block
structures.

## Usage

``` r
simdat
```

## Format

### `simdat`

A list with 3 matrices each with 150 rows and 50 columns:

- V1:V100:

  Data generated from multivariate normal with prespecified block
  structure for each of the 3 groups
